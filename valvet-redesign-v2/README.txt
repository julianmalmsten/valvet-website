VALVET — WEBSITE REDESIGN v2
======================================
Open index.html in your browser. Upload the entire folder to your web hosting.

FILE STRUCTURE
index.html      Main content, sections, and links
style.css       Readable, sectioned stylesheet with comments
script.js       Mobile menu, year and optional video playback
assets/         Original VALVET vector logo (SVG)
images/         Nine new supplied press photos
fonts/          Local Inter font files + bundled license

FONTS
The previous prototype used DM Sans / Manrope via Google Fonts.
Those exact files could not be downloaded in this environment.
This version uses locally installed Inter instead. Inter is open-source
(SIL Open Font License 1.1) and can be used on commercial websites.
No external font requests are made.

BRAND LOGO
The black SVG is generated from the supplied original Illustrator PDF.
It is displayed in black in the white header/footer, and inverted to white
by CSS on the photo hero. No font recreation of the logo is used.

OPTIONAL VIDEO
Place your 5-second, muted video in assets/hero-loop.mp4.
The page uses a still image until the video is actually playable.

BEFORE PUBLISHING
1. Check the YouTube link and replace it if necessary.
2. Confirm the live listing and link.
3. Replace merch placeholders with actual product photos when available.
4. Confirm that the linked EPK is the newest edition.
5. Keep /fonts and /assets when uploading; paths are relative.
